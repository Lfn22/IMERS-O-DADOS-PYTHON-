## 📋 Sobre o projeto

Dashboard interativo de análise de dados desenvolvido durante a **Imersão Dados** da Alura. Carrega dados de um arquivo CSV, processa com Pandas e exibe visualizações interativas via Streamlit — tudo rodando no navegador sem necessidade de configuração complexa.

---

## ✨ Funcionalidades

- 📂 Carregamento de dados via CSV
- 🔍 Filtros interativos por categoria e período
- 📈 Gráficos de evolução temporal
- 🏆 Ranking dos itens mais relevantes
- 📊 Métricas e totais automáticos
- 💾 Dados processados com Pandas

---

## 🚀 Como rodar localmente

### Pré-requisitos
- Python 3.8+
- pip

### Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/Lfn22/IMERS-O-DADOS-PYTHON-.git

# 2. Entre na pasta
cd IMERS-O-DADOS-PYTHON-

# 3. Instale as dependências
pip install -r requeriments.txt

# 4. Execute o app
streamlit run app.py
```

O dashboard abrirá automaticamente em `http://localhost:8501`
